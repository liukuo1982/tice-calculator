# 体测得分计算器

北京市小学四/六/八年级体测得分计算器，基于《国家学生体质健康标准（2014年修订）》。

## 部署方式

### Netlify（拖拽部署）
1. 打开 https://app.netlify.com/drop
2. 将本文件夹拖入页面
3. 获得在线地址

### Vercel
1. 安装 CLI: npm i -g vercel
2. vercel deploy

### GitHub Pages
1. 推送到 GitHub 仓库
2. Settings → Pages → Source: main branch
